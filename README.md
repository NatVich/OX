# OX

A kid-friendly OX (tic-tac-toe) game, hand-drawn on graph paper. Play against a friend on the same screen, or against the computer.

- Score is kept across rounds, and the loser of the last round goes first in the next one.
- The computer plays well but picks a random square now and then, so it can be beaten.
- Works in light and dark mode, on desktop and phone.

## Play

Open `index.html` in any web browser. No install or build step.
